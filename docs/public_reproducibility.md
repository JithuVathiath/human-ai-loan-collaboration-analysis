# Public Reproducibility Boundary

## What can be reproduced publicly

- Installation of the public package
- Schema validation on synthetic or authorised data
- Classification of the four reliance categories
- Reliance summary denominators and proportions
- Signed group-gap calculations
- Automated tests for deterministic public logic

## What requires controlled research data

- Reproduction of the dissertation's numerical findings
- Participant-level, applicant-level, round-level, or interaction-level analysis
- Transcript analysis and quotation context
- Complete grouped modelling, bootstrap intervals, SHAP analysis, and output manifests

## Why the boundary exists

The original data include controlled participant records, transcript material, timestamps, and other research information. Removing these records is a research-integrity and privacy safeguard, not an omission to be bypassed.

## Safe verification approach

The public package uses synthetic examples to verify deterministic logic. Synthetic outputs must never be presented as study findings. Verified study findings are reported in the README and notebook narrative, while their complete reproduction remains subject to the applicable research-data access process.
