# Data Dictionary

This document describes the main variables used by the analysis notebook.

## Applicant-level variables

- `participant_id` — anonymised participant identifier.
- `round` — experimental round number.
- `initial_decision` — participant's initial loan decision.
- `computer_decision` — recommendation provided by the computer system.
- `final_decision` — participant's final decision after viewing the recommendation.
- `correct_decision` — reference decision used for accuracy analysis.
- `group` — experimental applicant group.
- `loan_risk` — applicant loan-risk measure.

No real participant records are included in this repository.
